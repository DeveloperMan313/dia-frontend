# Let There Be Light Frontend

React приложение для расчета освещения помещений.

## Описание

Веб-приложение для просмотра каталога ламп и расчета освещения помещений. Приложение включает в себя:

- Главную страницу со статическим описанием
- Страницу списка услуг (ламп) с фильтрацией
- Страницу детальной информации о лампе
- Навигационную панель и хлебные крошки

## Технологии

- React 19
- TypeScript
- React Bootstrap
- React Router
- Vite

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение в режиме разработки:
```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

## Сборка для продакшена

```bash
npm run build
```

## Особенности

- Проксирование запросов для решения CORS
- Fallback на mock-данные при недоступности бэкенда
- Адаптивный дизайн с Bootstrap
- Фильтрация ламп по названию и мощности
- Дефолтные изображения для карточек

## API

Приложение использует API бэкенда по адресу `http://localhost:8001/api`. Основные эндпоинты:

- `GET /api/lamps` - получение списка ламп
- `GET /api/lamps/{id}` - получение информации о конкретной лампе

## Структура проекта

```
src/
├── components/     # React компоненты
├── pages/         # Страницы приложения
├── services/      # API сервисы
└── types.ts       # TypeScript типы
```

## Разработка

Для разработки убедитесь, что бэкенд сервис запущен на порту 8001, либо приложение будет использовать mock-данные.
